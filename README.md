# BeatCut Studio 0.5 — тестовый проект для Mac

**Начните с BeatCut_05_Tutorial_RU.txt.** В нём установка, все настройки и ограничения.
Это исходники для GitHub Actions, не готовое приложение .app.

## Возможности
- Монтаж под музыкальные акценты, случайные исходные фрагменты и переходы.
- Добавление/удаление видео без замены всего списка.
- Режимы повторов: свободно, редкие (мягкая пауза), без повторов исходных диапазонов.
- До 5 отдельных вкладок треков: своя музыка, видео, длина, Seed, повторы, цвет и эффекты.
- Последовательная очередь, не 5 параллельных рендеров. Тяжёлые операции между окнами сериализуются.
- Подгонка SDR-цвета каждого монтажного фрагмента к эталонному видео, с регулировкой силы.
- Зум, тряска, фиксация лица, слоумо, перемотка вперёд-назад и белые вспышки.
- Отдельная частота случайных событий каждого типа; одинаковый Seed фиксирует расписание.
- Подготовка предпросмотра только по нажатию; live-плеер выключен по умолчанию.
- Проверка путей, отмена и сохранение старого результата при неуспешной обработке очереди.

## Обновление существующего GitHub
1. Распакуйте BeatCut_Studio_05_GitHub.zip.
2. Загрузите содержимое папки в корень существующего BeatCut-Mac (не ZIP и не внешний каталог).
3. Commit changes в main.
4. **Обновите .github/workflows/build-mac.yml содержимым корневого build-mac.yml.**
   В браузере: Copy raw file у build-mac.yml -> карандаш у .github/workflows/build-mac.yml -> заменить текст -> Commit.
5. Actions -> Build BeatCut for Mac -> Run workflow. После изменений нужен новый запуск.
6. Скачайте нужный артефакт, распакуйте внешний и внутренний ZIP. Сохраните прежнее .app как резервную копию.

Цели: Intel macOS 12+, ARM64 macOS 14+. Developer ID / нотариализация не настроены.
Проверки Linux не доказывают совместимость с вашим Mac. Прочтите TEST_REPORT.md.
Версии библиотек и источники сохранены в requirements-build.txt и packaging/downloads.json.
При сбоях сети загрузчик делает до 4 попыток и выводит URL; HTTPS и SHA256 не отключены.

## Ограничения
Нет автоматического сохранения проектов, визуального поиска дублей, отдельных ручных дорожек,
AI-интерполяции, фиксации тела, ручного выбора лица и профессионального управления цветом.
Рандом эффектов не привязан к битам. Слоумо/перемотка могут сдвигать склейки внутри эпизодов.
Цвет — приблизительная статистическая коррекция SDR; HDR/LOG сначала конвертируйте отдельно.
Звук preview синхронизирован приблизительно. Вспышки опасны при фоточувствительности и требуют подтверждения.

## Проверки разработчика
Из app/: python -m unittest -v test_studio test_fx test_random_fx test_source_selection test_release05
Интеграция: python test_release05.py --integration /absolute/test/folder
GUI Linux: xvfb-run -a python test_release05.py --gui /absolute/test/folder (после интеграции).
Локальный запуск: python app/mac_entry.py; нужны Python/Tk, зависимости и FFmpeg/ffprobe.
В собранном .app зависимости включены. Пользователю Mac ставить Python отдельно не нужно.
