# Обновление BeatCut до тестовой версии 0.3

Это исходный проект для GitHub Actions, НЕ готовый файл .app. Сборка приложения происходит на GitHub. Видео и музыка никуда не загружаются при работе приложения.

## У вас уже есть репозиторий BeatCut-Mac

1. Сохраните прежнее рабочее приложение отдельно, если оно уже установлено. Эту версию сначала проверьте на коротком ролике.
2. Распакуйте **BeatCut_Studio_03.zip** на Mac.
3. Откройте свой существующий репозиторий **BeatCut-Mac**, вкладка **Code**.
4. Нажмите **Add file → Upload files**.
5. Из распакованной папки перетащите в браузер её содержимое:
   - **app** целиком — включая папку **models** и файл ONNX внутри;
   - **packaging** целиком;
   - **requirements-build.txt**;
   - **build-mac.yml**;
   - **README.md**;
   - **THIRD_PARTY.md**;
   - **UPDATE_03.md**;
   - **TEST_REPORT.md**;
   - **LICENSE**.
6. Загружайте именно содержимое, НЕ ZIP и НЕ внешнюю папку BeatCut_Studio_03. Подтвердите замену файлов через **Commit changes** в ветку **main**. История прежних версий останется в GitHub.
7. Скрытую папку **.github** повторно загружать НЕ требуется: сам workflow не изменился. Новые проверки вызываются из обновлённого кода внутри собранного приложения.
8. Откройте **Actions → Build BeatCut for Mac → Run workflow → main → Run workflow**.
9. Это должен быть **новый запуск**, не Re-run старого: иначе будет собран прежний код.
10. После зелёных галочек скачайте нужный артефакт:
    - **BeatCut-Intel-Monterey** — Intel / macOS 12.7.6;
    - **BeatCut-Apple-Silicon** — M5 / Tahoe 26.3.
11. Распакуйте ZIP GitHub, затем внутренний ZIP. Получится **BeatCut Studio.app**. Закройте старое приложение перед заменой. Новое окно должно называться **BeatCut Studio 0.3**.

Подпись Developer ID и нотариализация Apple по-прежнему не включены. Если macOS блокирует открытие, используйте штатное разрешение в настройках безопасности только для доверенной собственной сборки; не отключайте защиту всей системы.

Если задача красная: откройте её → красный шаг → пришлите последние 20–30 строк ошибки. Не меняйте macOS minimum и не удаляйте аудит совместимости ради зелёной галочки.

## Первый тест

1. Откройте приложение, нажмите **Открыть MP4…** и выберите короткий ролик с одним хорошо видимым лицом. Можно использовать уже сделанный монтаж.
2. Дождитесь подготовки кэша. Откроется плеер с ползунками справа.
3. Начните с **Zoom In / Out** и небольшой **тряски**, нажмите **Воспроизвести**, изменяйте ползунки.
4. На вкладке **Лицо** выполните анализ и затем включите фиксацию. Для рандома включите нужные эффекты на вкладках «Движение», «Лицо», «Слоумо», «Вспышки», затем откройте **Рандом**, включите случайные включения и выставьте частоту каждого эффекта (раз/минуту). Задайте длительность эпизода и посмотрите расписание. Seed делает результат повторяемым; кнопка «Перемешать эффекты» создаёт новое расположение.
5. Сохраните отдельный MP4 кнопкой экспорта и сравните его с предпросмотром.

Стробоскоп по умолчанию выключен. Быстрые белые вспышки опасны при фоточувствительности. Не включайте их без необходимости; учитывайте безопасность зрителей.

Это следующая работа, а не скрытые функции текущей версии.
