# Проверка 0.5

В Linux выполнено:
- 30 модульных тестов: PASS (планировщик, эффекты, случайные интервалы, повторы,
  реверс и его глубина, формула цвета, защита путей, очередь, отмена и сериализация операций).
- Реальный последовательный экспорт пяти проектов 160x90 / 30 FPS / 1.5 сек: PASS.
  Цвет, переходы, два проекта с рандомной перемоткой/зумом, аудио, по 45 кадров,
  декодирование полученных MP4 без ошибок.
- Отмена текущего проекта сохраняет существующий файл результата: PASS.
- GUI под Xvfb: пять независимых вкладок, настройки эффектов, обработка событий очереди,
  100% прогресс, безопасное состояние вспышек, ленивое открытие редактора,
  включение/выключение preview: PASS. При выключенном preview чтение кадров не вызывается.
- Старые тесты экспорта эффектов вызываются также в packaged self-test.

Тестовое окружение Linux отличается от закреплённых macOS Python/NumPy/SciPy.
Использованы OpenCV 4.10.0 и Pillow 11.1.0 из отдельной тестовой папки.
Новые GUI-тесты используют симуляцию очереди для проверки интерфейса; реальный
рендер очереди проверен отдельно интеграционным тестом. GUI не проверен на macOS.

НЕ выполнено здесь: сборка .app на GitHub, запуск на Intel Monterey и M5/Tahoe,
реальные длинные проекты, замеры FPS/памяти на Mac, оценка качества цвета и лица
на видео пользователя, нотариализация Apple. Это экспериментальная версия.
Статический аудит зависимостей от предыдущего этапа сохранён в packaging/new-wheel-audit.json;
он не заменяет аудит собранного bundle. Новых сторонних библиотек не добавлялось.
