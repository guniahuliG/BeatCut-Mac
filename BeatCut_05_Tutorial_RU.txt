BEATCUT STUDIO 0.5 — ПОНЯТНЫЙ УЧЕБНИК
=====================================
Экспериментальная версия. Исходный проект для сборки Mac-приложения через GitHub.
Код, интерфейс и короткие экспорты проверены на Linux. Это не подтверждает запуск
готового .app на Monterey или Tahoe: сборку и проверку на Mac ещё нужно выполнить.

1. ЧТО ПРОГРАММА УМЕЕТ
----------------------
Программа выбирает кусочки из видео, собирает их в случайном порядке под музыку
и применяет выбранные переходы. Она ищет музыкальные акценты эвристически:
это не разделение инструментов и не гарантия идеального попадания каждой склейки.

Есть два способа работы:
А) Одиночный: исходники + музыка -> собрать черновик -> по желанию настроить
   эффекты с предпросмотром -> сохранить отдельный финальный MP4.
Б) Очередь: отдельные вкладки, у каждой своя музыка и видео -> по желанию цвет
   и эффекты -> один запуск -> отдельный финальный MP4 для каждого проекта.

Обработка локальная. Пользовательские видео не нужно загружать в GitHub.
Интернет нужен для скачивания зависимостей при сборке приложения на GitHub,
но не для модели лица во время монтажа: модель включена в проект.

2. ОБНОВЛЕНИЕ ЧЕРЕЗ GITHUB
--------------------------
Новый репозиторий не нужен. Используйте существующий BeatCut-Mac.
1) Скачайте BeatCut_Studio_05_GitHub.zip и распакуйте его.
2) В GitHub откройте BeatCut-Mac -> Code -> Add file -> Upload files.
3) Загрузите СОДЕРЖИМОЕ папки BeatCut_Studio_05: app, packaging и файлы рядом.
   Не загружайте сам ZIP или внешнюю папку целиком как дополнительный уровень.
4) Commit changes в main.
5) В ЭТОМ обновлении изменён workflow. Скрытую .github Finder может не показать.
   Надёжный способ: откройте загруженный build-mac.yml в корне GitHub,
   нажмите Copy raw file; затем откройте .github/workflows/build-mac.yml,
   нажмите карандаш, замените весь текст скопированным и Commit changes.
   Если файла ещё нет: Add file -> Create new file, имя
   .github/workflows/build-mac.yml, вставьте текст и сохраните.
6) Actions -> Build BeatCut for Mac -> Run workflow -> main -> Run workflow.
   После обновления кода нужен НОВЫЙ запуск, а не повтор старого запуска.
7) Дождитесь завершения. Intel и Apple Silicon собираются отдельными задачами.
8) Скачайте BeatCut-Intel-Monterey для Intel либо BeatCut-Apple-Silicon для M-чипа.
   Внешний ZIP артефакта GitHub содержит внутренний ZIP с .app. Распакуйте оба.
9) Закройте старую программу. Сохраните её резервную копию и замените новой.
   В заголовке главного окна должно быть BeatCut Studio 0.5.

Цели сборки: Intel macOS 12+, Apple Silicon macOS 14+. На ваших конкретных
Monterey 12.7.6 и M5/Tahoe нужна отдельная проверка. Нотариализации Apple нет.
Разрешайте запуск только собственной доверенной сборки штатными средствами
macOS. Не отключайте защиту всей системы. В случае ошибки пришлите её текст.

3. ПЕРВЫЙ РОЛИК
----------------
1) Добавьте 3–5 коротких видео. Выберите музыкальный файл.
2) «Сохранить как…»: новый файл, например test_draft.mp4.
3) Выберите стиль «Клиповый». Длина: 10 секунд. Для теста — 640x360 или HD.
4) Повторы: «Редкие повторы», пауза 8 секунд. Цвет сначала выключен.
5) Нажмите «1. Собрать черновик» и дождитесь окончания.
6) Для проверки эффектов нажмите «2. Предпросмотр / эффекты».
7) Нажмите «Подготовить предпросмотр / эффекты» и дождитесь подготовки.
8) Включите Live preview, включите зум и нажмите «Воспроизвести».
9) Выберите «Рандом», включите случайную расстановку, настройте частоту.
10) «Экспорт MP4 с эффектами…»: сохраните test_final.mp4 отдельно от черновика.

4. ВИДЕО, МУЗЫКА И РЕЗУЛЬТАТ
----------------------------
«Добавить видео…» можно нажимать много раз: новые файлы ДОБАВЛЯЮТСЯ, а не заменяют
список. Можно выбирать из разных папок. Один и тот же разрешённый путь не добавится
дважды. Разные копии одного видео с разными именами считаются разными исходниками.

Выделите строки списка и нажмите «Удалить выбранные из списка».
На главном экране также есть «Очистить список» с подтверждением.
Эти кнопки не удаляют оригиналы с диска. Полный путь выбранного файла виден ниже.

Фиксированного лимита исходников в одном проекте нет. Это НЕ обещание обработки
любого объёма: нужны память, место и время. Начинайте с короткого теста.

Один проект = один музыкальный трек + свой набор видео + один MP4.
Звук исходных видео не используется в монтаже. В результат идёт выбранная музыка.
«Открыть MP4…» открывает уже готовый ролик для эффектов: это не добавление его
в список исходников. Цвет для такого MP4 автоматически заново не выравнивается.

5. СТИЛЬ МОНТАЖА И SEED
-----------------------
«Спокойный», «Клиповый», «Динамичный» устанавливают готовые сочетания ползунков.
После выбора стиля любые параметры можно изменить вручную.

Плотность склеек: выше -> чаще смены кадров.
Разнообразие ритма: выше -> больше разброс длительностей и коротких серий.
Минимальный кадр: нижняя граница длительности монтажного фрагмента, в секундах.
Максимальный кадр: верхняя граница. Минимум не должен превышать максимум.
Последний очень короткий фрагмент и короткий трек могут иметь особые границы.

Длина, сек.: 0 означает весь аудиотрек. Положительное число ограничивает длину
началом трека. Если музыка короче указанной длины, результат ограничится музыкой.

Seed монтажа: целое неотрицательное число. Один Seed + те же файлы и настройки
дают воспроизводимый план. Пустое поле означает новый случайный Seed при запуске.
Чтобы перемешать сам МОНТАЖ, создайте новый черновик с другим/пустым Seed.
Перемешивание эффектов не меняет последовательность выбранных видеофрагментов.

6. ПОВТОРЫ ОДНОГО И ТОГО ЖЕ МОМЕНТА
-----------------------------------
Блок «Повтор исходных моментов» относится к СБОРКЕ ЧЕРНОВИКА.

Свободно: повторно выбирать один исходный временной диапазон можно в любой момент.
Редкие повторы: сначала ищет ещё не использованные участки. Когда новых подходящих
нет, избегает участков, которые использовались совсем недавно. Пауза измеряется
в секундах итогового видео, от конца прежнего фрагмента до начала нового, включая
участие в переходах. Если выполнить паузу невозможно, она может быть ослаблена:
монтаж не прерывается. Это мягкое предпочтение, не строгая гарантия паузы.
Без повторов: выбранные временные диапазоны одного файла не пересекаются во всём
проекте. Учитываются дополнительные кадры для переходов. Если план не удаётся
разместить, программа остановится до рендера. Добавьте видео или сократите монтаж.
Планировщик эвристический: неудачная раскладка не всегда доказывает, что никакой
другой раскладки не существует. Можно попробовать другой Seed или границы кадров.

Запрет не распознаёт визуальные дубли в разных файлах или повторяющиеся движения,
уже записанные внутри исходника. Он также не отменяет художественное повторение
при слоумо/перемотке: это отдельные эффекты, которые намеренно повторяют кадры.
Ручного запрета конкретного участка и поиска похожих сцен пока нет.
В отчёте .beatcut.json у выбранных фрагментов есть start, frames и repeat.

7. ПЕРЕХОДЫ
------------
Частота переходов: доля склеек, на которых программа пробует применить переход.
0 -> обычные склейки. Больше -> больше переходов. Длительность ограничивается
длинами соседних кадров; на слишком коротких участках переход может не примениться.
Выбранные галочками типы участвуют в случайном выборе:
- Наплыв: плавное смешивание изображений.
- Сдвиг влево / вправо: один кадр уходит, другой появляется сбоку.
- Шторка вверх: направленное раскрытие следующего кадра.
- Круговое раскрытие: открытие по кругу.
- Пикселизация: переход через крупные пиксели.
Конец перехода привязан к выбранному акценту. Если акцентов не найдено, используются
временные склейки. Это не тот же параметр, что частота зума или тряски в эффектах.

8. ЭКСПОРТНЫЕ НАСТРОЙКИ
-----------------------
HD 1280x720: быстрее и легче. Full HD 1920x1080: больше деталей и нагрузки.
Вертикально 1080x1920: вертикальный ролик. Квадрат 1080x1080: квадратный.
Быстрый тест 640x360: для проверки идеи, не финального качества.
FPS: 24, 25, 30 или 60. Выбор 60 не дорисовывает отсутствующие кадры.
Заполнить с обрезкой: кадр заполняет экран, края могут обрезаться.
Вписать с полями: сохраняется весь кадр, могут появиться чёрные полосы.
Быстрый черновик / Обычное / Высокое: компромисс скорости, размера и качества.

Окно эффектов экспортирует в разрешении подготовленного черновика. Если черновик
640x360, эффекты не вернут исходную Full HD-детализацию. Дополнительное кодирование
может ухудшать качество. Экспорт эффектов использует H.264 CRF 18 / veryfast.
HDR, 10-bit, профессиональное управление цветом и AI-интерполяция не поддержаны.

9. ПРИВЕСТИ ВИДЕО К ПОХОЖЕМУ ЦВЕТУ
----------------------------------
На главном экране: «Выравнивание цвета SDR по эталону».
1) Выберите короткий эталонный ролик с нужным естественным цветом.
2) Включите «Смягчённо подгонять цвет каждого фрагмента».
3) Начните с силы 0.3–0.55. 0 -> нет коррекции, 1 -> максимальная ограниченная.
4) Соберите короткий черновик. Сравните с вариантом без коррекции при том же Seed.

Программа берёт несколько уменьшенных кадров выбранного фрагмента и эталона,
сравнивает средние значения и разброс каналов, затем применяет ограниченную
коррекцию RGB. Для всего фрагмента параметры постоянны: нет покадровой автоматики,
которая могла бы заставить яркость пульсировать. Коррекция запекается ДО переходов.
В предпросмотре виден уже скорректированный черновик — второй коррекции там нет.

Это приблизительное согласование, не профессиональный color match и не LUT-пакет.
Сильно разные сюжеты (ночь/день, лес/снег) могут дать плохой результат. Снижайте силу.
Эталон лучше выбирать без длинных титров, чёрных полей и резких смен освещения.
HDR PQ/HLG с корректными тегами отклоняется при включённом match. LOG и неверно
помеченный HDR не всегда можно автоматически распознать: сначала переведите в SDR
во внешнем редакторе. Выключение match само по себе НЕ является HDR->SDR конвертацией.
В каждой вкладке очереди можно выбрать свой эталон и силу коррекции.

10. ПРЕДПРОСМОТР — ТОЛЬКО КОГДА НУЖЕН
--------------------------------------
Главное окно и очередь не запускают видеоплеер автоматически.
При открытии окна эффектов расчёт ещё НЕ начинается. Нажмите «Подготовить
предпросмотр / эффекты», если хотите работать с этим роликом в редакторе.
Подготовка один раз перекодирует мастер с постоянным FPS и лёгкий proxy до 640x360,
а также извлечёт звук. Это требует CPU и места, даже если live-плеер ещё выключен.

После подготовки Live preview всё ещё выключен: видеокадры не декодируются
и эффекты для экрана не вычисляются. Включите галочку Live preview, затем Play.
Выключение галочки останавливает проигрывание и убирает изображение.
«Без эффектов» показывает черновик без текущих дополнительных эффектов; цвет,
который уже запечён при монтаже, этот переключатель не отменяет.
Полоса под изображением перематывает ролик. «В начало» возвращает к нулю.
Можно менять ползунки на паузе или во время проигрывания.

Звук на Mac воспроизводится системным afplay; синхронизация приблизительная.
При перегрузке preview пропускает кадры. Финальный экспорт считается покадрово.
Для минимальной нагрузки работайте через очередь: она применяет эффекты без плеера.
При экспорте эффекты рассчитываются независимо от состояния галочки Live preview.

11. ГДЕ ДЕЙСТВУЮТ ЭФФЕКТЫ
-------------------------
Вверху панели «Область эффектов»: Начало, Конец и Плавность краёв.
Без рандома все включённые эффекты используют один общий участок.
В рандоме этот участок ограничивает область, ВНУТРИ которой генерируются эпизоды.
Например, Начало 3, Конец 15: случайные зум/тряска не появятся до 3 и после 15 секунд.
Плавность краёв смягчает вход/выход геометрии и яркости. Слоумо/перемотка имеют
собственную формулу времени, этот ползунок не превращает реверс в плавный переход.
Нет отдельных вручную добавляемых дорожек и ключевых кадров.

12. ЗУМ И ТРЯСКА
----------------
Вкладка «Движение». Сначала включите нужную галочку.
Zoom In / Out: сила задаёт величину приближения; период — время одного цикла.
«Пульс» приближает и отдаляет. «Приближение» движется в одну сторону;
«Отдаление» — в другую. Односторонние режимы сбрасываются на следующем цикле.
Если эпизод очень короткий относительно периода, зум будет менее заметен.

Тряска: смещение — доля меньшего размера кадра, частота — скорость колебаний в Гц,
поворот — угловая тряска в градусах. Начните со смещения 0.01–0.025 и поворота 1–2.
Запас кадрирования 1.0–2.0 увеличивает изображение, скрывая края при смещении.
За границей кадра используется отражение картинки, оно иногда заметно.
Увеличьте запас или снизьте силу, если по краям видны повторённые части изображения.

13. ФИКСАЦИЯ ЛИЦА
------------------
Вкладка «Лицо» -> «Проанализировать лицо» -> дождаться -> включить фиксацию.
В очереди отдельная кнопка анализа не нужна: при включённой фиксации он запускается
автоматически после монтажа. Предупреждение в настройках очереди объясняет это.
Сила фиксации 0–1: насколько сильно удерживать лицо у выбранного программой якоря.
Сглаживание: больше -> плавнее траектория, но менее жёсткое удержание движения.
Компенсировать наклон: выравнивает угол линии глаз.
Удерживать размер: меняет масштаб, чтобы расстояние между глазами было стабильнее.
Целевой размер лица: фактически расстояние между глазами как доля ширины кадра.

Лучше работает с одним хорошо видимым лицом. При нескольких людях возможны
переключения; при перекрытии/повороте головы трекинг может теряться. Это не фиксация
тела и не распознавание личности. Нет ручного выбора человека. Анализ локальный.

14. СЛОУМО И ПЕРЕМОТКА
----------------------
Вкладка «Скорость».
Слоумо -> плавный догон: первая половина эпизода замедляется, вторая ускоряется,
сохраняя общую длину и прежнюю музыку. Минимальная скорость 0.5 — примерно половина
обычной в самой медленной точке; 1 — нет замедления. AI-дорисовки нет, будут повторы.

«Перемотка вперёд -> обратно»: движение идёт вперёд, резко разворачивается назад
до начального момента эпизода, затем ускоренно догоняет текущую позицию ролика.
Так сохраняются общая длительность и непрерывность выбранной музыки.
Глубина перемотки определяет, сколько исходного движения захватывает рывок.
В пределах эпизода: первые 40% — вперёд, следующие 30% — обратно, последние 30% —
догон. При глубине 1 рывок проходит примерно 42% длины эпизода по исходному времени.
При совпадении с эпизодом слоумо перемотка имеет приоритет. Не включайте оба
одновременно без проверки: на границе совпадений возможна заметная смена скорости.

Это эффект уже собранного черновика. Если эпизод пересекает склейку, назад пойдут
и склейки. Для эффекта с машиной лучше участок внутри одного непрерывного плана.
Склейки внутри слоумо/перемотки могут сместиться с музыкальных акцентов.

15. БЕЛЫЕ ВСПЫШКИ
------------------
ОПАСНО ПРИ ФОТОЧУВСТВИТЕЛЬНОСТИ: быстрые вспышки могут вызвать приступ, головную
боль или дискомфорт. Низкая яркость не гарантирует безопасность. Предупредите зрителей.
По умолчанию выключены. Включение требует подтверждения предупреждения.
Яркость 0–1: сила белого наложения.
Мигание, Гц: сколько вспышек за секунду ВНУТРИ серии.
Длительность вспышки: доля периода, в течение которой белый слой включён.
Например, при 5 Гц и доле 0.2 вспышка длится около 0.04 секунды.
При низком FPS и пропусках preview короткие вспышки выглядят иначе или теряются.

16. РАНДОМ ЭФФЕКТОВ
--------------------
1) На обычных вкладках включите нужные эффекты и настройте силу.
2) Во вкладке «Рандом» включите «Случайно размещать эффекты».
3) Для каждого типа задайте частоту от 0 до 30 событий в минуту.
   0 -> этот тип не появляется в рандоме. Для вспышек это СЕРИИ в минуту, не Гц.
4) «Эпизод: от / до» — общий диапазон случайной длины события для всех типов.
5) «Показать моменты» — точные интервалы текущего расписания и Seed эффектов.
6) «Перемешать расписание» — новый вариант, не пересобирающий сам монтаж.

Пример: 12 зумов/мин на 30-секундном участке -> около 6 эпизодов зума.
Число округляется случайно, на коротком участке редкий эффект может не появиться.
При длинных эпизодах событий будет меньше, чтобы одинаковые эффекты не перекрывались.
Разные эффекты могут совпадать. Повышение частоты пересчитывает расположение.
Изменение силы не перемешивает расписание. Для нового варианта нажмите кнопку.

Рандом фиксирован: те же параметры дают те же моменты в preview и экспорте.
Seed эффектов отдельный от Seed монтажа; посмотреть его можно в списке моментов.
Это случайные моменты по времени, НЕ автоматическое назначение новых эффектов по битам.
«Выключить эффекты» снимает галочки типов; режим рандома может остаться включённым.

17. ОЧЕРЕДЬ 1–5 ПРОЕКТОВ
------------------------
1) Сначала в главном окне настройте ОБЩИЕ стиль, размер, FPS, качество и переходы.
2) Нажмите «Очередь 1–5 треков…». Откроются три вкладки; можно добавить до пяти.
   Они копируют общие настройки на момент открытия очереди. Последующие изменения
   главного окна в уже открытые вкладки не переносятся.
3) В каждой вкладке: имя, свой список видео, своя музыка и свой путь MP4.
4) Личные настройки вкладки: длительность, Seed, повторы и пауза, цвет/эталон/сила.
5) Для эффектов нажмите «Настроить эффекты этого трека…». Сначала выберите музыку.
   Панель такая же, как в редакторе; видеоплеера в этом окне нет. Закрытие окна
   настройки его скрывает и сохраняет значения в памяти текущей вкладки.
6) Включите «Применить эффекты после монтажа», иначе результат будет без них.
7) Снимите «Включить проект в очередь» у ненужных вкладок. Совсем пустые вкладки
   пропускаются автоматически; частично заполненная включённая вкладка требует
   заполнить обязательные файлы, иначе очередь не стартует.
8) Нажмите «Обработать очередь». При существующих результатах будет подтверждение.
9) Программа последовательно делает монтаж -> цвет -> выбранные эффекты -> MP4.
   Для каждого проекта отдельный результат. Цвет фактически применяется внутри
   подготовки фрагментов; анализ лица для эффектов — после сборки черновика.
10) Следите за статусом каждой вкладки. Ошибка одного проекта не отменяет остальные.
11) «Результат выбранного трека…» открывает его редактор только по вашему нажатию.

ВАЖНО: это потоковая ПОСЛЕДОВАТЕЛЬНАЯ очередь, а не пять одновременных рендеров.
Ограничение одного тяжёлого расчёта действует и между окнами этой копии приложения.
Если запустить другую операцию во время очереди, она может ждать освобождения
обработчика. Это экономит память, но не делает сам рендер лёгким для CPU.
Во время запуска настройки очереди заблокированы и используются снимки параметров.
Для изменения остановите очередь, дождитесь остановки и затем редактируйте.
Каждый повторный запуск обрабатывает все включённые заполненные вкладки заново.

Если после настройки эффектов заменить музыку или длину проекта, проверьте
«Начало / Конец»: прежние значения сохраняются; конец будет ограничен длиной
готового ролика. Для длинного нового трека удобнее заново открыть очередь.
Вкладки не сохраняются между перезапусками программы. Автосохранения проектов нет.

18. ЭКСПОРТ И ОТМЕНА
---------------------
Одиночное окно эффектов сохраняет новый MP4. Настройки фиксируются при нажатии
экспорта. Изменение ползунков потом влияет на preview, а не на начатый экспорт.
Очередь тоже использует снимки, оригиналы не меняются. Запрет путей проверяет
совпадения результатов с исходниками/музыкой/эталонами всех проектов очереди.

«Остановить очередь» отменяет текущий проект и пропускает остальные.
Успешно завершённые результаты остаются. Старый файл текущего результата
сохраняется до успешного завершения всех этапов, затем атомарно заменяется.
Анализ аудио и отдельные операции декодера могут закончить текущий этап не сразу.
Не закрывайте приложение силой: дождитесь снятия статуса обработки.

Сборка черновика и очередь пишут рядом .beatcut.json: Seed, план, переходы,
повторы и настройки. «Сохранить настройки JSON…» в редакторе — отдельный отчёт
эффектов, не проект, который можно загрузить обратно. Редактор сам по себе
не создаёт .beatcut.json автоматически. Сохраните настройки отдельно, если нужны.
Временные файлы удаляются при нормальном закрытии/завершении. При аварии кэш может
остаться в системной временной папке или в .beatcut-job-* у папки результатов.

19. РЕЦЕПТЫ ДЛЯ СТАРТА
-----------------------
Спокойный: стиль «Спокойный», зум 0.08–0.15, рандом 4–6/мин, эпизоды 1–2 секунды.
Клиповый: стиль «Клиповый», зум 0.2, тряска 0.015, частоты 10 и 6/мин,
эпизоды 0.4–1.2 секунды. Вспышки выключены.
Машина вперёд-назад: длинный непрерывный кадр, область 2–4 секунды внутри него,
перемотка включена, глубина 0.75–1, остальные временные эффекты выключены.
Много одинаковых кадров: режим «Без повторов», больше исходников, короткий итог.
Разный цвет: короткий нейтральный эталон, сила 0.3, проверить лица и белые объекты.
Слабый Mac: 30 FPS, HD или тестовый размер, один расчёт, preview выключен.

20. ОШИБКИ И ЧЕСТНЫЕ ОГРАНИЧЕНИЯ
--------------------------------
Не видно эффекта: включён ли сам тип? Включён ли Live preview? Не включено ли
«Без эффектов»? Попадает ли время в область? Для рандома частота больше нуля?
Есть ли событие в «Показать моменты»? Лицо проанализировано и найдено?

Повторы остались: «Редкие» не строгий запрет; отдельные копии видео не распознаются.
Слоумо и перемотка сами намеренно повторяют кадры. Проверьте «Без повторов» без них.
Странный цвет: уменьшите силу или выключите match; проверьте SDR и выбор эталона.
Тормозит: выключите Live preview. Если идёт экспорт/анализ, CPU всё равно занят.
Не стартует очередь: заполните включённые проекты, проверьте уникальные пути MP4.
Нет свободного места: сокращайте тест, уменьшайте разрешение, освобождайте диск.

GitHub: DNS / nodename not known означает, что сервер сборки не разрешил адрес
скачивания. Новый загрузчик выводит URL и делает до четырёх попыток, сохраняя
проверку SHA256 и HTTPS. Это не исправит постоянно недоступный адрес или сеть.
После завершения запуска можно Re-run failed jobs. При изменении кода — новый Run.
Если ошибка повторяется, пришлите название красного шага и последние строки лога.

Пока нет: визуального поиска дублей, ручных отдельных дорожек/кейфреймов,
AI slow motion, фиксации тела, ручного выбора лица, автопроектов, пяти параллельных
рендеров, профессионального color management и точной аудиосинхронизации preview.
Случайный монтаж может выбрать неудачный момент — всегда смотрите итог перед публикацией.
